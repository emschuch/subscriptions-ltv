# Subscriptions LTV

Project exploring simulated subscriptions data to determine the value of users by acquisition channel.

The [notebook](https://github.com/emschuch/subscriptions-ltv/blob/main/notebooks/subscriptions-ltv.ipynb) is used to explore and reshape the data for visualization in a [Tableau dashboard](https://public.tableau.com/app/profile/em.schuch/viz/subscriptions-ltv/UserLTV).
